# 🚀 MachineTestCrud – ASP.NET MVC CRUD Project

A simple and beginner-friendly **CRUD (Create, Read, Update, Delete) Web Application** developed using ASP.NET MVC and SQL Server. This project is designed to practice database operations and understand the fundamentals of .NET web application development.

## 📌 Project Overview

MachineTestCrud is a practice project that demonstrates how to perform basic CRUD operations in an ASP.NET MVC application connected to a SQL Server database.

## ✨ Features

- ➕ **Create:** Add new records to the database.
- 📋 **Read:** Display and view existing records.
- ✏️ **Update:** Edit and update existing records.
- 🗑️ **Delete:** Remove records from the database.
- 🗄️ **Database Connectivity:** Connect the application to SQL Server.
- 🎨 **User Interface:** Simple and user-friendly web pages.

## 🛠️ Technologies Used

- **Frontend:** HTML, CSS, Bootstrap
- **Backend:** C#, ASP.NET MVC
- **Database:** Microsoft SQL Server
- **Data Access:** ADO.NET or Entity Framework, depending on the project implementation
- **IDE:** Visual Studio

## ⚙️ How to Run the Project

1. Clone or download this repository.
2. Open the solution file (`.sln`) in Visual Studio.
3. Open SQL Server Management Studio (SSMS).
4. Create or configure the required SQL Server database and tables.
5. Update the database connection string in `Web.config`.
6. Restore any required NuGet packages.
7. Build the solution.
8. Press **Ctrl + F5** to run the application.

## 🎯 Learning Objectives

- Understand the ASP.NET MVC architecture.
- Learn how Controllers, Models, and Views work together.
- Implement Create, Read, Update, and Delete operations.
- Connect a web application to SQL Server.
- Practice database management and debugging.
- Gain hands-on experience for .NET developer machine tests.
